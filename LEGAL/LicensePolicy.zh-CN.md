# SparkArc 开源许可与社区使用说明

生效日期：2026年4月19日

本文档用于说明 SparkArc 的开源许可、社区自部署边界、官方实例运营边界，以及第三方使用时应遵守的基本规则。

- 本文档用于项目治理与公开说明，不构成正式法律意见。
- 若本文档与 `LICENSE` 中的 AGPL-3.0 正文存在冲突，以 `LICENSE` 的许可正文为准。

## 1. 项目许可

除非文件或子目录另有说明，SparkArc 主项目基于 GNU Affero General Public License v3.0 only（AGPL-3.0-only）发布。

你可以在遵守 AGPL-3.0 的前提下运行、复制、研究、修改、部署和分发 SparkArc。

如果你修改 SparkArc，并通过网络向用户提供服务，应按 AGPL-3.0 要求向这些用户提供该版本的完整对应源代码，并保留原始版权、许可证和来源声明。

## 2. 火柴 Agent 网关的单独许可

`server/llm/agen_matchbox` 目录下的火柴 Agent 网关是由同一维护者开发的独立可复用组件，按该目录内 `LICENSE` 以 Apache License 2.0 单独授权。

该 Apache-2.0 授权仅适用于 `server/llm/agen_matchbox` 目录中明确受其覆盖的组件，不改变 SparkArc 主项目其他部分的 AGPL-3.0-only 授权。

## 3. 社区友好的自部署立场

维护者欢迎以下使用方式：

- 个人部署自用
- 创作者、小团队、工作室内部部署
- 学习、研究、二次开发与本地创作流程整合
- 按 AGPL-3.0 合规要求公开修改版源码的第三方部署
- 通过 Issue、PR、文档、模板、Agent、工作流、教程等方式参与生态建设

维护者会尽力保持 SparkArc 长期开源。维护者自行开发的新功能，原则上优先同步到公开仓库。

## 4. 官方实例与维护者自营

SparkArc 的官方实例仅指由 Mournight / AIdeaStudio 明确公布并持续列入官方实例名单的服务入口。

官方实例未来可能以公益、赞助、付费额度、托管服务或其他方式维持项目持续开发。该等官方实例运营行为不改变 SparkArc 主项目的 AGPL-3.0-only 开源许可。
