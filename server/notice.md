# V0.9.0 Homer 发布

这是SparkArc一切的开始。版本号——荷马（Homer），致敬这位史诗之祖。

在这个版本中，我们构建了互动叙事引擎的基石。SparkArc 不仅仅是一个编辑器，它是一个由 AI 驱动的创意伙伴，旨在帮助创作者打破灵感的边界。

### 🌟 核心特性

#### 1. 多智能体协作系统 (Multi-Agent System)
我们引入了基于角色的 AI 协作流。不再是单一的对话，而是专业的团队为您服务：
- **导演 (Director)**：把控叙事节奏与方向。
- **编剧 (Scriptwriter)**：生成具体的对话与描写。
- **世界观管理者 (Lorebook)**：确保设定的一致性与深度。
- **评论家 (Critic)**：提供改进建议与反馈。

#### 2. ARC 剧本引擎
专为互动叙事打造的 `.arc` 格式，支持非线性剧情结构、场景管理与元数据标记。让故事的组织如同代码般严谨，又如诗歌般自由。

#### 3. 现代化创作工坊
- **全新 UI**：基于 Vue 3 + Naive UI 构建的现代化界面，提供流畅的交互体验。
- **项目管理**：完整的文件树与资源管理。
- **灵活配置**：支持自定义 LLM 模型接入，让您掌握核心算力。

### 🚀 快速开始
1. 在 **设置** 中配置您的 LLM API Key。
2. 创建一个新的 **项目**。
3. 在 **世界观** 中添加您的设定。
4. 让 AI 协助您生成第一幕场景。

### 🔮 未来展望
Homer 只是开始。在未来的版本中，我们将带来：
- 更强大的可视化节点编辑器。
- 实时语音与多模态支持。
- 社区分享与插件生态。
