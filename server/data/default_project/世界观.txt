# 《雨停在四点十七分》世界设定

## 舞台

故事发生在日本海一侧的小城汐见町。这里没有著名景点，只有一条半空置的旧商店街、一座小车站和走十分钟就能看见的防波堤。梅雨季节，潮气会钻进榻榻米和信封，住户习惯在玄关放一块擦不干的旧毛巾。

商店街中段的“白鹭洗衣房”开了三十七年。店里有六台洗衣机、三台烘干机、一张贴着透明胶的长椅，以及一只总慢两分钟的圆钟。最里面的机器脱水时会向左挪两三厘米，熟客会用折叠杂志垫住它的脚。

## 时间与生活

故事集中在六月下旬的一个星期四，从下午两点四十分到四点十七分。雨下得很密，电车偶有晚点。附近小学四点放学，商店街的可乐饼店五点前会卖完当天最后一锅。

这里没有超自然规则。人物受到的限制都很普通：钱不够宽裕，工作不能随便请假，不擅长的话拖得太久，衣服湿了就得想办法晾干。也正因为如此，一次借伞、一团饭和一句没有追问的话，才会在日后留下分量。

## 白鹭洗衣房

洗衣房由安西澄江照看。柜台后有热水壶、针线盒、失物篮和一本手写账簿。墙上贴着三张澄江写的告示，其中“请取出口袋里的纸”少了一个角。停电时，卷帘门旁的手摇装置可以放出洗衣机里的水，但店里没有备用发电机。

洗衣房不是秘密据点，也不替人解决人生。它只是让等待有了座位，让不愿回家的人可以多坐二十分钟。

## 叙事边界

- 现实主义日常剧，情绪来自细小动作和未说尽的话，不依赖巧合、绝症或宏大灾难。
- 雨并非悲伤的象征；它首先是天气，会弄湿鞋袜、拖慢交通，也会让陌生人暂时待在同一屋檐下。
- 结尾不承诺人物从此痊愈。岛村灯只做出一个有限而具体的决定：把刚租下的房间收拾好，至少住完这个夏天。
