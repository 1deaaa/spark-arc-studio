# 📢 公告板 (Notice Board)

欢迎使用 **SparkArc**！这是一个专为互动叙事设计的 AI 创作引擎。

### 最近更新
- [2025-12-25] 核心架构从 Flask 完整迁移至 **FastAPI**，性能大幅提升。
- [2025-12-20] 增强了角色扮演代理的逻辑一致性。
- [2025-12-15] 新增了对更多自定义 AI 平台的支持。

### 使用提示
- 您可以在“外观设置”中调整您喜欢的 UI 配色。
- 在“平台管理”中配置您的 API Key 后，即可开始创作。
- 遇到问题？请查看 [GitHub 项目页面](https://github.com/sparkarc) 获取更多帮助。

*祝您创作愉快！*
