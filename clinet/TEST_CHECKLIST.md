# 迁移修复验证清单

## 快速测试步骤

### 1. 亮色模式按钮测试 ✓
**步骤**:
1. 确保系统处于亮色模式
2. 查看顶部工具栏按钮
3. 检查按钮文字和边框是否清晰可见

**预期**: 按钮有清晰的边框和深色文字，hover 时有明显的视觉反馈

---

### 2. 对话树节点边框测试 ✓
**步骤**:
1. 打开任意故事文件
2. 查看对话树中的节点
3. 点击不同节点观察边框变化

**预期**: 
- 未选中节点有灰色细边框
- 选中节点有明显的蓝色边框
- hover 时边框颜色变化

---

### 3. 新建文件/文件夹测试 ✓
**步骤**:
1. 在文件树空白处右键
2. 选择"新建故事文件"或"新建文件夹"
3. 应该弹出输入框
4. 输入名称并确认

**预期**: 
- 右键菜单正常显示（Naive UI 样式）
- 输入框在鼠标位置附近弹出
- 输入后能成功创建

**测试用例**:
- 在根目录新建
- 在文件夹内右键新建
- 重命名文件
- 删除文件（确认框）

---

### 4. 右侧面板滚动测试 ✓
**步骤**:
1. 选择一个对话节点
2. 右侧对话编辑器应显示完整表单
3. 尝试添加多个行为(act)直到超出屏幕
4. 检查是否出现滚动条

**预期**: 
- 内容超出时自动出现滚动条
- 可以滚动到底部查看所有按钮
- 滚动流畅无卡顿

---

### 5. 深浅色模式切换测试 ✓
**步骤**:
1. 打开 Windows 设置 → 个性化 → 颜色
2. 切换"选择模式"（浅色/深色）
3. 观察应用是否实时响应

**测试点**:
- [ ] 头部工具栏颜色变化
- [ ] 文件树背景和文字颜色
- [ ] 对话树卡片颜色
- [ ] 右侧表单输入框颜色
- [ ] 输入框内没有奇怪的蓝色背景

**特别检查深色模式**:
- 对话内容文字是否清晰（不应该太灰）
- 输入框背景应该是深色且无色块覆盖
- 所有文字都应该有足够的对比度
